## 簡介
- 遊戲標題：魂匠守衛者
- 遊戲類型：2D俯視角守塔+策略+資源管理
- 目標平台：PC(Steam)
- USP：不只是像傳統守塔一樣布置防線, 還可以在防線間透過調度魂件的方式玩出創新而截然不同的策略體驗, 整體遊戲節奏緊湊不冷場, 考驗玩家的臨場反應

## 核心玩法
![[game_play.png|456]]
這是一款守塔類遊戲, 玩家操控角色, 抵抗持續進攻的怪物, 玩家可以做的事情是：

1. 從主堡購買物件, 物件分成兩種類型：靜態單位、移動單位, 各自有不同的放置方式
2. 可以取下所有單位(敵方單位的屍體上、我方單位、中立單位、防禦塔甚至主堡…等)身上的魂件, 在不同單位間安裝、組合, 讓不同單位發揮出戰術性的效果, 例如：
    1. 把士兵身上的「自動索敵」和「近距離攻擊」拆下來裝在防禦塔上, 使防禦塔可以走路去追蹤敵人和近戰攻擊
    2. 把防禦塔的「遠程攻擊」拆下來裝在士兵上, 使士兵同時有遠近兩種攻擊方式
    3. 把多個防禦塔的「遠程攻擊」拆下來集中在同一座防禦塔上, 使之遠攻能力變得更加強大等
3. 把敵方士兵身上的「進攻主堡」拆下來裝在中立單位上, 讓中立單位往主堡前進, 當進入主堡後, 即可從主堡購買該單位
4. 當敵方士兵被擊殺後會噴金幣, 必須靠近撿金幣, 而金幣可以去主堡購買物件

每個單位都會有魂件槽位上限, 某些單位的槽位上限可以升級擴充。

當玩家抵抗了數個進攻波次直到最後一波次, 把所有敵方單位消滅後即該關卡勝利, 依據玩家是否滿足該關卡的設定條件, 給予0~3顆星星的評價, 星星數可以用來解鎖後續關卡或成就。

玩家在該關卡所取得過的魂件和進入過主堡的中立單位都會解鎖, 未來會出現在主堡的購買清單中提供給玩家選擇。

當玩家完成關卡, 回到大地圖上, 可以選擇繼續推進到下一關卡或重玩舊關卡。大地圖上也會有一些特殊事件點, 各有不同的升級效果例如升級各種單位的魂件槽位、降低購買價格、提升玩家角色的能力等。部分特殊事件點和關卡需要一定的星星數才可解鎖。

## 遊戲關卡設計概念

* 除新手教學關卡外, 預計設計50個關卡左右
* 非完全線性通關, 基本上讓玩家同時可以有2~4個關卡供選擇
* 平均每3~5個關卡就會有一個特殊事件點供玩家觸發
